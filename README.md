# Memory Card

***О приложении***
Данное приложение предназначено для специальстов культурного центра «Человек мира». Вам предстоит ответить на вопросы о мировой культуре, народностях и их языках.\

***Правила пользования***
При запуске на экране выводятся вопросы с вариантами ответов, необходимо отметить правильный ответ и перейти на экран, где будет указан правильный вариант ответа. После ознакомления переходите к следующему вопросу.\
